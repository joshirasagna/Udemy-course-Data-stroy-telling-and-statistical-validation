Data Storytelling & Statistical Validation
?? Project Overview
This project analyzes Udemy course data to identify factors influencing course popularity, learner engagement, and course performance. The analysis combines Exploratory Data Analysis (EDA), data storytelling, dashboard visualization, and statistical hypothesis testing to generate actionable business insights. 

?? Business Objective
The objective of this project is to:
* Analyze Udemy course data. 
* Identify key factors affecting course popularity. 
* Compare free and paid courses. 
* Understand subscriber behavior. 
* Provide data-driven business recommendations. 

?? Dataset Information
The dataset contains information about Udemy courses, including:
* Course Title 
* Subject 
* Price 
* Number of Subscribers 
* Number of Reviews 
* Number of Lectures 
* Content Duration 
* Paid/Free Status 
Dataset Summary:
* Total Courses: 3,678 
* Paid Courses: 3,367 
* Free Courses: 310

?? Statistical Validation
Hypothesis Testing
Null Hypothesis (H?):
There is no significant difference in subscribers between paid and free courses.
Alternative Hypothesis (H?):
There is a significant difference in subscribers between paid and free courses. 
Test Used
Two-Sample T-Test 
Results
MetricValueAlpha0.05P-Value0.032DecisionReject H?Conclusion
The statistical test confirms that there is a significant difference in subscriber counts between paid and free courses.
